# Environment-Assisted Quantum Transport in Open Quantum Chains

Code and data for the paper *Environment-Assisted Quantum Transport in Open
Quantum Chains: Optimal Dephasing, Disorder Statistics, and the Limits of the
Enhancement Ratio* (manuscript v6, `main.tex`).

---

## The idea

Environment-assisted quantum transport (ENAQT): in a network of coupled sites
with a trap, moderate dephasing noise can raise the probability that an
excitation reaches the trap. Too little noise and energy mismatch or
localization block transport; too much and the dynamics freeze (quantum Zeno
effect). In between, the trapping yield has a maximum.

We compute the yield exactly within a Lindblad model (pure dephasing, an
irreversible trap, uniform loss) from one linear solve per parameter point.

---

## Main results (numbers regenerated by `scripts/paper_numbers.py`)

1. Mismatch rule: in linear funnels of fixed total bias the optimal dephasing
   rate equals the nearest-neighbour energy mismatch, gamma* = eps_tot/(N-1),
   to within 2% for N = 2 to 20, and to within 15% when the trap and loss
   rates change by two decades. This is the Haken-Strobl-Reineker resonance on
   every bond, the trapped-chain version of the rule Jacob et al. (2024) found
   for boundary-driven tilted chains. It also holds for square lattices.
2. Pure dephasing is an infinite-temperature bath, so the yield is exactly
   unchanged when the bias is reversed (uphill = downhill), and the flat chain,
   which shows no ENAQT, beats every funnel. Dephasing repairs yield lost to
   energy mismatch; it does not give the funnel an advantage.
3. ENAQT is typical in disordered chains: 974 of 1,000 chains (sigma = 2 Delta,
   N = 2 to 15) have an interior yield maximum with at least 1% gain. Only 4
   of them beat the flat chain; weak disorder matched to the funnel's step
   beats the funnel.
4. The enhancement ratio eta_peak / eta_ref depends on the reference point,
   the total bias and the rates (plateau 36-38 against gamma = 1e-3 only for
   eps_tot = 5 Delta and the default rates; 1.3e3 against gamma = 0 at N = 20;
   about 1.6 for eps_tot = 2 Delta). Maximizing it over site energies has no
   finite optimum and lowers the yield.
5. FMO (Adolphs-Renger Hamiltonian, source BChl 1, trap BChl 3):
   gamma* = 1.9 Delta_FMO, of the order of a standard estimate of the protein
   dephasing rate. The 4.7-fold enhancement falls to 1.14 at biological trap
   and loss rates.

Recommendation: report peak yield and optimal dephasing rate; give the ratio
only together with the exact reference point and rates used.

Note: earlier versions of this README and of the draft claimed HEOM
validation of the trapping model, a ~2.1N enhancement law, "disorder amplifies
ENAQT" and "the funnel is the optimal disorder". Those claims are withdrawn;
see the paper, Sec. III and Appendix A.

## What's in this repo

| Path | What it does |
|------|-------------|
| `main.tex` | Manuscript v6 (inline bibliography, no bibtex needed) |
| `figures/` | The four main-text figures |
| `scripts/paper_numbers.py` | Recomputes the paper's numbers (about 80 s on one core) -> `paper_numbers.json` |
| `scripts/make_paper_figures.py` | Draws `figures/` from `paper_numbers.json` |
| `src/enaqt/` | Installable package (`pip install -e .`) with CLI and tests |
| `enaqt_*.py` | Original exploratory scripts and their JSON/PNG outputs |
| `enaqt_optimal_disorder.py`, `enaqt_2d_lattice.py` | Produce the optimizer and 2D results used in the paper |
| `PAPER_ENAQT_DRAFT.md` | Superseded v3 draft, kept for the record |

## Quick start

```bash
pip install -e ".[dev]"
python scripts/paper_numbers.py          # writes paper_numbers.json
python scripts/make_paper_figures.py     # writes figures/
pytest
```

If linear algebra is very slow on your machine, set `OPENBLAS_NUM_THREADS=1`
(the test suite does this automatically).

The original HEOM script (`enaqt_sb_analysis.py`) needs the QD3SET-1
spin-boson dataset from
[figshare](https://doi.org/10.25452/figshare.plus.c.6389553), placed in
`../SB/data/`. It is not needed for the paper's results.
