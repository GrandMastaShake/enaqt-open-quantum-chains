# Environment-Assisted Quantum Transport in Open Quantum Chains

Code and data for the paper *Environment-Assisted Quantum Transport in Open
Quantum Chains: Length Scaling, Disorder Statistics, and the Limits of the
Enhancement Ratio* (manuscript v5, `main.tex`).

---

## The idea

Environment-assisted quantum transport (ENAQT): in a network of coupled sites
with a trap, moderate dephasing noise can raise the probability that an
excitation reaches the trap. Too little noise and energy mismatch or
localization block transport; too much and the dynamics freeze (quantum Zeno
effect). In between, the trapping yield has a maximum.

We compute the yield exactly within a Lindblad model (pure dephasing, an
irreversible trap, uniform loss) from one linear solve per parameter point.

---

## Main results (all numbers regenerated by `scripts/paper_numbers.py`)

1. The optimal dephasing rate tracks the energy mismatch: about equal to the
   bias for two sites, and falling as N^-1.20 for linear funnels of fixed total
   bias (N = 2 to 20). The peak yield falls from 0.80 to 0.25 over that range.
2. ENAQT is typical in disordered chains: 974 of 1,000 chains (sigma = 2 Delta,
   N = 2 to 15) have an interior yield maximum with at least 1% gain.
3. The enhancement ratio eta_peak / eta_zero is dominated by the coherent
   baseline. Against gamma = 1e-3 it plateaus near 38 for long funnels; against
   gamma = 0 it keeps growing (1.3e3 at N = 20). Disordered chains reach larger
   ratios than the funnel only because their baseline collapses; their peak
   yield is lower at every N. Optimizing site energies for the ratio gives a
   step profile whose peak yield is again below the funnel's.
4. FMO (Adolphs-Renger Hamiltonian, source BChl 1, trap BChl 3): 4.7-fold
   enhancement at gamma* = 1.9 Delta_FMO, of the order of a standard estimate
   of the protein dephasing rate.

Recommendation: report peak yield and optimal dephasing rate; give the ratio
only together with the exact reference point used for eta_zero.

Note: earlier versions of this README and of the draft claimed HEOM
validation of the trapping model, "disorder amplifies ENAQT" and "the funnel is
the optimal disorder". Those claims are withdrawn in v5; see the paper,
Sec. III and Appendix A.

## What's in this repo

| Path | What it does |
|------|-------------|
| `main.tex` | Manuscript v5 (inline bibliography, no bibtex needed) |
| `figures/` | The four main-text figures |
| `scripts/paper_numbers.py` | Recomputes every number in the paper (about 40 s) -> `paper_numbers.json` |
| `scripts/make_paper_figures.py` | Draws `figures/` from `paper_numbers.json` |
| `src/enaqt/` | Installable package (`pip install -e .`) with CLI and tests |
| `enaqt_*.py` | Original exploratory scripts and their JSON/PNG outputs |
| `enaqt_optimal_disorder.py`, `enaqt_2d_lattice.py` | Produce the optimizer and 2D results used in the paper |
| `PAPER_ENAQT_DRAFT.md` | Superseded v3 draft, kept for the record |

## Quick start

```bash
pip install -e ".[dev]"
python scripts/paper_numbers.py          # writes paper_numbers.json
python scripts/make_paper_figures.py     # writes figures/
pytest
```

If linear algebra is very slow on your machine, set `OPENBLAS_NUM_THREADS=1`
(the test suite does this automatically).

The original HEOM script (`enaqt_sb_analysis.py`) needs the QD3SET-1
spin-boson dataset from
[figshare](https://doi.org/10.25452/figshare.plus.c.6389553), placed in
`../SB/data/`. It is not needed for the paper's results.
